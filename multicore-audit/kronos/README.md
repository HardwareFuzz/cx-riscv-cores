# Kronos

Canonical Kronos is a single-core implementation. The audited source does
not provide a multi-core parameter, coherent interconnect, CLINT/PLIC/IPI
fabric, or multi-hart response-routing path.

The HardwareFuzz dual-core compliance wrapper and its runner observations
were therefore not accepted as confirmed Kronos HDL/RTL records. This
directory intentionally contains no record.md files.
