# ISA Profiles

Per-core RISC-V extension and instruction support data, generated by
[riscv-instruction-scanner](https://github.com/HardwareFuzz/riscv-instruction-crates)
from the RTL sources under `cores/`.

## Files per core

| File | Description |
|---|---|
| `supported.csv` | Per-extension verdict: `support_status`, `isa_bases`, `evidence_kind`, `distinct_instructions`, `sample_files`, `notes` |
| `extensions_found.csv` | Extensions detected by the scanner with hit counts per path class |
| `instructions_found.csv` | Every matched instruction with asm / hdl occurrence counts |

`support_status` values:
- **used** — at least one instruction occurrence found in asm or HDL
- **declared** — only `-march` / Scala ISA string / build parameter evidence (no instruction hits)

## Regenerating

```bash
# From riscv-instruction-crates repo:
cargo build --release -p riscv-instruction-scanner

BINARY=./target/release/riscv-scan
CORES=/path/to/cx-riscv-cores/cores
OUT=/path/to/cx-riscv-cores/isa-profiles

for core in boom cva6 ibex kronos openc906 openc910 picorv32 picorv32_2hart_wt rocket-chip VexRiscv XiangShan XiangShan-cx-2hart; do
    case $core in
        cva6)   EXCL="--exclude verif/**" ;;
        openc*) EXCL="--exclude smart_run/**" ;;
        *)      EXCL="" ;;
    esac
    $BINARY scan --target $CORES/$core --out $OUT/$core --include-hdl $EXCL
    $BINARY verdict --scan $OUT/$core
done
```
